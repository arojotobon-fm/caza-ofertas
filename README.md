# Caza Ofertas

Página pública de ofertas verificadas para la temporada decembrina.

- `index.html`: la página (sin dependencias, se publica tal cual en Netlify).
- `data/ofertas.json`: los productos. Se actualiza cada vez que Ana pide "actualiza ofertas".

Cada producto lleva la hora de verificación; la página marca como "puede haber cambiado" lo que tenga más de 12 horas.
